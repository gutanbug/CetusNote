# 브랜드 컨셉 — CetusNote

> 결정(2026-11-19, 사용자): 앱 이름은 **CetusNote**. 고래자리(Cetus)를 담은 노트를 배경으로 별자리의 느낌을 살린다.
> 이 문서는 그 결정을 기존 디자인 원칙(`tokens.md`) 안에서 어떻게 표현할지 정한다.

## 1. 이야기

- **고래자리(Cetus)** 는 가을 남쪽 하늘의 큰 별자리다. 밝은 별이 드문드문 흩어져 있어, 점을 이어야 비로소 고래 모양이 보인다.
- 노트도 그렇다. 흩어진 메모(별)를 이으면(링크·멘션·백링크) 생각의 모양(별자리)이 드러난다. **CetusNote = 흩어진 생각을 잇는 노트.**
- 고래자리의 **미라(ο Ceti, "놀라운 별")** 는 몇 달에 걸쳐 밝아졌다 어두워지는 변광성이다. 앱에서 유일하게 따뜻한 색 점으로 표시해 "오늘 다시 밝아지는 생각"을 상징한다.

## 2. 표현 원칙 (기존 원칙과의 관계)

| 원칙             | 별자리 표현에서 지킬 것                                                                                                                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| Quiet hierarchy  | 점과 가는 선이 바탕. 빛은 별이 밝아질 때만 같은 색으로 옅게 번진다(2026-11-20 사용자 요청). 스플래시·첫 설정은 물론 홈·페이지·빈 상태도(radiant) 별 둘레에 방사형 그라데이션 빛을 쓴다. 채색 하늘·그라데이션 배경·네온은 쓰지 않는다. |
| 포인트 색은 하나 | 별자리 색은 포인트 색과 분리된 **잉크 색(`--sky-*`)** 이다. 미라만 따뜻한 색을 쓴다.                                                                                                                                                  |
| 라이트 / 다크    | 라이트 = 종이에 인쇄한 **성도(星圖)** — 남색 잉크 점과 연한 선. 다크 = **밤하늘** — 밝은 점과 어두운 선.                                                                                                                              |

| 사실성           | 별 위치·밝기는 실제 하늘의 근삿값(적경·적위 → 평면 투영, 등급 → 점 크기)을 쓴다. 가짜 별자리를 그리지 않는다.                                                                                                                         |

## 4. 하지 말 것

- 별자리를 본문 글자 뒤에 깔기(가독성), 화면 전체를 덮는 별 하늘.
- 우주 사진, 성운, 은하수 그라데이션. (반짝이는 별·옅은 빛은 2026-11-20 사용자 요청으로 빈 상태·홈·페이지에 허용)
- 고래 그림(만화 고래)과 별자리 선을 섞기 — 선과 점만으로 고래를 떠올리게 한다. **예외(2026-11-23 사용자 결정): 앱 아이콘만 고래 실루엣 + 별자리를 쓴다**(§3 "로고 · 앱 아이콘" 참고). 이 예외는 앱 아이콘에만 적용하고 화면 안 그림에는 적용하지 않는다.
- 별자리 색을 포인트 색(`--accent`)으로 칠하기.

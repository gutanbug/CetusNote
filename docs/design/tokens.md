# 디자인 토큰

코드의 토큰 소스(`src/styles/tokens.css` → Tailwind `@theme`)는 이 표와 **값이 같아야** 한다.

- **출처:** OpenDesign 프로젝트 "노트 워크스페이스 앱 프로토타입"의 `app.css` `:root` / `:root[data-theme="dark"]`, `app.js` `ACCENTS`, `components.html` §19–22. 2026-11-19에 추출했고, 2026-11-20에 아래 메모의 값을 OpenDesign에 다시 맞췄다(`/design-sync`).
- **우선순위:** 초기 디자인 요청값보다 프로토타입에서 다듬어진 **이 문서의 값이 우선**한다(예: 반경, 회색 계열, accent).
- **변경 절차:** OpenDesign에서 먼저 바꾼 뒤 이 문서와 `tokens.css`를 함께 갱신한다. 코드에서만 값을 바꾸지 않는다.
- 이름은 프로토타입 CSS 변수명을 그대로 쓴다(`--bg-app` 등). Tailwind에서는 `bg-app`, `text-primary` 같은 유틸리티로 노출한다.

# 기능 명세 (Feature Spec)

CetusNote가 제공할 기능의 단일 목록. 구현·리뷰·커밋에서 **기능 ID**(`SHELL-01` 등)로 참조한다.

- 출처: 초기 디자인 요청서 + OpenDesign 프로토타입(`index.html`, `app.js`).
  프로토타입에만 있는 기능(공간, 탭, 컬렉션 뷰, 빠른 메모 등)도 포함했다.
- 우선순위: **P0** = 첫 사용 가능 버전(MVP) · **P1** = 바로 다음 · **P2** = 나중 · **제외** = 범위 밖
- 상태: `계획` → `진행` → `완료` (완료 = 해당 화면 조립 + 감사 통과)
- 사용 컴포넌트 ID는 [`docs/design/components.md`](../design/components.md) 참조.

## 범위 밖 (제외)

단일 사용자 · 로컬 우선 · DB 없음 원칙에 따라 아래는 만들지 않는다.

| 항목                        | 이유                                                |
| --------------------------- | --------------------------------------------------- |
| 로그인/로그아웃, 계정, 멤버 | 단일 사용자 로컬 앱                                 |
| 공유, 댓글(💬), 실시간 협업 | 서버 필요. Tiptap Cloud 미사용                      |
| 클라우드 동기화             | 범위 밖. 대신 폴더 단위 백업/내보내기 제공          |
| AI 글쓰기 기능              | Tiptap AI(유료) 미사용                              |
| 공간(Space, 구 SHELL-12)    | 폴더(SHELL-14)가 같은 역할 — 2026-11-20 사용자 결정 |

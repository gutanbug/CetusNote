# 다른 앱에서 가져오기 안내

설정 데이터 · 명령 팔레트 「다른 앱에서 가져오기…」 · 파일 메뉴에서 시작해요. 앱을 카드에서 고르고, 그 앱의 내보내기 안내를 따라 파일을 준비한 뒤 zip 파일이나 폴더를 골라 주세요.

> 이 문서는 `src/features/import/apps/guides.ts`(대화상자가 그리는 원천)와 같은 내용이에요. 안내를 바꾸면 두 곳을 함께 고쳐요.

## 앱별 안내

### Notion

- **읽는 것:** Markdown & CSV 내보내기 zip (페이지는 Markdown, 데이터베이스는 CSV)
- **고를 것:** zip 파일 (압축을 풀지 마세요)

내보내는 방법:

1. 가져올 최상위 페이지를 열고 오른쪽 위 •••(더보기)를 눌러요.
2. •••에서 「More」를 열고 「Export」를 눌러요.
3. 형식에서 「Markdown & CSV」를 고르고, 「하위 페이지 포함(Include subpages)」을 켜요.
4. 「내보내기」를 누르면 받는 zip 파일을 그대로 골라요.

워크스페이스 전체는 설정 → 일반 → 「Export all workspace content」로 받을 수 있어요. 준비에 시간이 걸리고, 메일로 받는 링크는 7일 뒤 만료돼요.

가져와요: 페이지 본문(제목·목록·표·코드·그림)과 하위 페이지 구조, 데이터베이스(CSV)는 컬렉션으로 옮겨요.
가져오지 않아요: 관계·수식·롤업 열(값으로 옮기지 않아요), 댓글과 버전 기록.

### Obsidian

- **읽는 것:** 보관소(vault) 폴더
- **고를 것:** 폴더(주), 또는 보관소를 압축한 zip

내보낼 필요는 없어요. 보관소 폴더를 그대로 고르면 돼요. 안의 `.obsidian` 폴더는 건너뛰어요.

가져와요: 노트(.md)와 front matter(title·tags·aliases), `#태그`, 위키링크·별칭, 그림(`![[그림]]`), 콜아웃(`> [!종류]`).
가져오지 않아요: 캔버스(.canvas)와 플러그인 데이터, 보관소 밖에 있는 그림.

### AppFlowy

- **읽는 것:** Markdown 또는 HTML로 내보낸 파일과 폴더
- **고를 것:** 폴더(주), 또는 zip

내보내는 방법:

1. 가져올 페이지마다 •••(더보기)를 눌러 「Export」에서 「Markdown」을 골라요. 데이터베이스는 「CSV」로 내보내요.
2. 받은 파일과 그림을 한 폴더에 모아 두세요. 그림은 문서 기준 상대 경로로 찾아요.
3. 「폴더」를 누르고 그 폴더를 골라요.

AppFlowy 공식 도움말에는 닿지 못했어요. 커뮤니티 공지(forum.appflowy.com)에서 페이지별 Markdown·CSV 내보내기를 확인했어요(2026-11-23). 메뉴 이름은 버전에 따라 다를 수 있어요.

가져와요: Markdown·HTML 문서와 하위 문서 구조, 그림, CSV 데이터베이스(컬렉션).
가져오지 않아요: AppFlowy 작업공간 내부 형식, 데이터베이스의 관계·수식·롤업 열.

### AFFiNE

- **읽는 것:** Markdown으로 내보낸 파일과 폴더
- **고를 것:** 폴더(주), 또는 zip

내보내는 방법:

1. 문서 메뉴에서 「Markdown」 내보내기를 골라요. 공유 패널에도 같은 내보내기 메뉴가 있어요.
2. 가져올 문서마다 반복해서 받고, 한 폴더에 모아 두세요.
3. 「폴더」를 누르고 그 폴더를 골라요.

AFFiNE 공식 블로그(v0.27.4 기준, 2026-10-09 확인)에서 문서 메뉴의 「Markdown」 내보내기를 확인했어요. 상위 「내보내기」 메뉴 이름은 그 글에서 확인하지 못했고, 메뉴 이름은 버전에 따라 다를 수 있어요.

가져와요: Markdown 문서와 그림(index.md와 assets 폴더), CSV 데이터베이스(컬렉션).
가져오지 않아요: AFFiNE 원본 파일(.affine·.bs.zip)과 문서 스냅샷. Markdown으로 내보내 주세요. 화이트보드 내용.

### 출처 (2026-11-23 확인)

- Notion: 공식 도움말 「Export your content」 (notion.com/help/export-your-content). 단일 페이지는 •••·More·Export, 형식 「Markdown & CSV」, 「Include subpages」. 메일 링크 7일.
- Obsidian: 공식 도움말 「Vault」 (obsidian.md/help/vault). 보관소는 로컬 폴더이므로 내보내기가 필요 없어요. `.obsidian` 설정 폴더 설명은 이 페이지에 없어서 확인하지 못했어요.
- AppFlowy: 공식 문서 색인은 가져오지 못했어요. 커뮤니티 공지(forum.appflowy.com/t/…/2743 「export a document page as an .md file」)와 mintlify 미러로 확인했어요. 공식 메뉴 이름은 미확인.
- AFFiNE: 공식 블로그 「How to Export and Share Your Online Whiteboard」(affine.pro/blog/how-to-export-and-share-your-online-whiteboard), v0.27.4 기준. 문서 메뉴와 공유 패널의 「Markdown」 항목. 상위 「내보내기」 라벨은 미확인.

## 제한

| 항목                       | 한도     |
| -------------------------- | -------- |
| zip 파일 한 개             | 512MB    |
| 텍스트 파일 한 개          | 10MB     |
| 그림·첨부 파일 한 개       | 25MB     |
| 항목 수(zip 안 파일)       | 20,000개 |
| 한 번에 가져오는 전체 크기 | 2GB      |

한도를 넘으면 그 항목은 「읽지 못했어요」 목록에 들어가요. 나머지는 그대로 가져와요.

## 문제 해결

- **다른 앱을 골랐어요.** 「…에서 내보내기」 화면에서 「앱 고르기」로 돌아가 다시 고르세요. 파일이 맞지 않으면 「이 앱의 내보내기에서 문서를 찾지 못했어요」 안내가 나와요.
- **AFFiNE 원본 파일을 골랐어요.** 원본(.affine·.bs.zip)은 가져올 수 없어요. AFFiNE에서 Markdown으로 내보낸 뒤 다시 고르세요.
- **그림이 안 보여요.** 그림 파일이 내보낸 폴더 안에 있는지 확인하세요. 문서 기준 상대 경로로 찾아요.
- **가져온 뒤 「N개를 가져왔고 M개는 읽지 못했어요」가 나와요.** 읽지 못한 항목 이름을 확인하세요. 파일이 깨졌거나 한도를 넘었을 수 있어요.
- **큰 보관소는 오래 걸려요.** 문서를 하나씩 저장하므로 수천 개는 시간이 걸릴 수 있어요.

## 가져온 뒤

- 가져온 문서는 「<앱>에서 가져옴」 묶음에 들어가요. 묶음은 「어디에 넣을까요?」에서 고른 곳 아래에 만들어져요.
- 문서 사이의 링크는 가져온 새 문서를 가리켜요.
- 원본 앱의 파일은 바꾸지 않아요.

### Evernote

준비: 가져올 노트북을 우클릭하고 「노트북 내보내기」를 골라요. 형식에서 「ENEX」를 고르고 저장해요. 노트북마다 .enex 파일이 하나씩 생겨요.

가져오는 것: 노트 본문(글꼴·목록·표·링크)과 체크 목록, 그림과 첨부 파일, 태그, 만든 날·고친 날. 파일 이름이 노트북 폴더가 돼요.

가져오지 않아요: 암호화된 노트(자리에 안내 글만 남겨요), 원본이 없는 그림(건너뛰고 요약에 개수를 알려요).

고르기: 「ENEX 파일 고르기」를 누르고 .enex 파일을 골라요. 여러 개를 한 번에 고를 수 있어요. 메뉴 이름은 Evernote 버전에 따라 다를 수 있어요.
